# LCARS for Obsidian: Style Guide

The Picard-era LCARS palette as this theme uses it. Every color in the frame has a job, so each one is listed with where it appears. Change colors in **Style Settings → LCARS Palette**; the geometry is fixed.

Light mode is not supported yet. The last column records the current draft mapping, for later.
